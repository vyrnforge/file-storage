# Contributing

Phase 1: FS-100A only. Read AGENTS.md and project constitution before work. Use focused branches and reviewable PRs. Keep docs, decisions and backlog consistent. Run `python3 scripts/check-foundation.py` from the repo root. Do not import private legacy artifacts, introduce secrets, start unapproved runtime work, publish packages, deploy or merge without owner approval.

After approval add reproducible builds, contract and negative security tests, dependency/security scans, and local/hosted CI parity. Target stable check name ci. VyrnRail governance is a reference; provider controls must be independently applied and verified. Active branch rules and CI merge gate verified; see repository security evidence.
