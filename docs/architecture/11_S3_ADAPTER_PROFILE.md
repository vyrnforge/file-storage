Owner authorized [#25](https://github.com/vyrnforge/file-storage/issues/25) conditional on prerequisites, after DEC-FS012 approval in PR #56. This branch is stacked on the verified revised contract; merge into main requires PR #56 acceptance/merge and fresh compatible CI. No production provider approval.

## Engineering prerequisites selected
- AWS Java SDK 2.57.2, S3 and Apache sync HTTP client, from Maven Central. See [artifact versions](https://central.sonatype.com/artifact/software.amazon.awssdk/s3/versions) and [conditional writes](https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-writes.html). Pin in adapter module; no vendor types in domain/application/security/SPI. Kernel remains 0.3.2.
- Isolated disposable MinIO RELEASE.2025-04-22T22-12-26Z, [release](https://github.com/minio/minio/releases/tag/RELEASE.2025-04-22T22-12-26Z), via Testcontainers 1.21.4. Synthetic credentials generated in test; HTTP only inside disposable test. Two unversioned buckets, path-style, explicit region, no cloud URL/env/default credentials. No claim for AWS itself or other targets until their own evidence. Image tag not digest pinned; vulnerability review and image digest pinning before actual target release.
- Required profile: create-only conditional PutObject If-None-Match *, no HEAD/unconditional PUT fallback; short/long input rejected before external write. Single PUT uses private bounded spool and fixed-size buffer; explicit byte and concurrent staging caps. Fixture 1 MiB, four spool permits, 15s maximum call, two test locations. No production defaults. Spool ownership, access, disk encryption, quotas, crash cleanup and caller input idle/deadline enforcement are future gateway/deployment gates.
- Validate unversioned status before use; versioned/suspended profile and explicit providerVersion unsupported. Profile must prohibit out-of-band versioning changes (admin/permissions validation #28); validation snapshot not continuous detection. Delete missing exact unversioned key succeeds. No optional capabilities advertised (multipart/copy/presign). Large-file multipart planned separately after verified completion semantics, not simulated by unsafe unconditional PUT.
- Each adapter instance accepts exactly one backend identity and rejects overlapping configured prefixes in the same bucket. Cross-instance/revision overlap prevention remains registry #27/#28. SDK client supplied by trusted composition with bounded pool/connect/socket/API timeouts, no automatic retries for uncertain effects; adapter owns client and per-request remaining budget. Caller owns input and must supply bounded/cancellable input (arbitrary blocked InputStream cannot be forcibly interrupted safely); adapter checks deadline between reads and before external write. Returned stream has deadline watchdog abort, early close aborts rather than drains. No whole-file memory materialization. No provider I/O inside metadata transaction. No raw SDK causes or messages in SPI failures. If staging cleanup fails, capacity permit withheld until restart/reconciliation; operational cleanup gate.
- Internal cursor scope/location/prefix bound, random opaque cursor mapped to provider token; bounded TTL/entries, invalid/evicted/restarted cursors fail closed. Instance-local, no cross-instance durability guarantee. Required key listing only. SHA-256 null (not inferred from ETag); integrity worker must independently verify bytes.

Verify shared regressions and seven readable POMs. Actual network stall, provider-specific permission distinctions, SDK transitive vulnerability/secret redaction review, AWS and target S3 compatibility, TLS/egress/credentials, crash spool cleanup, distributed cursor strategy, optional capabilities and large-file throughput remain separate release gates. No production S3 account, gateway, worker, CDN or deployment. PR stacked on #56; no merge performed. Local full verification remains outstanding.
