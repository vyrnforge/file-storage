## Privilege drift and credential lifecycle

V2 checks effective table/column/schema/function permissions and grant options, role attributes and membership edges, database CONNECT/TEMP/CREATE baseline and public schema CREATE, explicit default ACL grants to service roles/PUBLIC, service relation ownership. PostgreSQL 17 baseline PUBLIC CONNECT/TEMP is recorded, not treated as production best practice. Test-only detection, no automatic remediation. Default ACL coverage is conservative (explicit grants), not exhaustive inspection of every cluster role or external schema; sequences, all database role settings, function/schema ownership, grantor chains, actual connection policy and production ACL inventory remain separate gates.

Isolated password rotation denies new old-credential sessions; existing connection remains usable until membership revoked; NOLOGIN blocks new connections. Rotation and revocation do not automatically cancel in-flight transactions. Production secret manager, pool drain/termination, break-glass and rotation monitoring must be approved and rehearsed.

## Restore and restart

Disposable logical archive (no owner/ACL restore) into separate database owned by non-superuser migration login. Revoke PUBLIC CONNECT/TEMP before restore, restore as explicit owner, rerun migrations/readiness, check relation ownership and preserved upload/pending event count. Because no-ACL restore recreates default PUBLIC routine execution, quarantine explicitly revokes PUBLIC schema/table/function privileges, removes default PUBLIC function EXECUTE for the migration owner, and disables every restored manifest mapping before access. Verify raw and audited function execution denied; source principal remains unchanged. Dispatcher cannot connect until explicit CONNECT and scoped profile granted; test in-memory publisher, repeated dispatch does not resend published rows, source outbox unchanged; revoke CONNECT to prevent new sessions. Real transport replay remains at-least-once and requires reconciliation/deduplication; no actual broker delivery. Database in same PostgreSQL cluster, no cross-cluster/PITR/encryption/RPO/RTO certification. Quarantine network and existing sessions, disable all restored manifest mappings before enabling service logins, review role IDs and permissions and explicitly reprovision all needed function grants (including the legacy invoker helper for backend administration), validate data and reconcile pending/claimed outbox rows, then independently approve dispatch. No production restore or deployment.
