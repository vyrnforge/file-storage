## Quota primitives

Separate per-session ledger; reserve exact durable initiation expected_size and exact tenant/file/version/location/session, current activation revision, INITIATED and unclaimed/unexpired session. Tenant advisory lock serializes all reservations and activation with arbitrary precision sum, so concurrent requests cannot exceed isolated limit. Reserve replay same pinned revision returns existing status; no double charge. Settlement checks current session and DB guard: RESERVED -> CHARGED only clean completed available with matching scan size; RESERVED -> RELEASED only failed/expired and no claimed write. Claimed/uncertain upload keeps reservation pending separately verified cleanup. Charged rows never release, including soft delete/restore; no purge accounting. Settlement retains pinned revision across policy replacement. Atomic audit/outbox and immutable identity/terminal state. Usage reports ledger-only reserved/charged, not physical usage or complete tenant quota; no automatic integration into initiation/completion/recovery and no backfill of existing sessions. Production enforcement requires same transaction integration, migration/backfill, roles, scope and limit approval, load and failure verification. No provider I/O.
