## Proposed target responsibilities (preserve existing eight modules)

Domain: immutable domain/value types and lifecycle invariants; split broad model by aggregate only if API compatibility retained. Application: explicit use-case orchestration/ports. Security: trusted token/identity and authorization policy, no persistence/provider coupling. Persistence: grouped metadata/catalog, control plane, transfers, lifecycle/governance/quota, durable work; shared transaction/statement primitives with explicit scope and correct resource ownership. SPI: provider-neutral contracts. S3/OSS: adapter, SDK factory and stream/spool ownership. Runtime: composition/role admission, HTTP transport, transfer orchestration and scheduled workers; no provider SDK imports outside adapters. Keep audit/outbox atomic and logical identity stable.
