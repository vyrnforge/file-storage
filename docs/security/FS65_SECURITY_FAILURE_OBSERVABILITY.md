# FS-65 AQ-03B — bounded security failure observations

Status: proposed implementation, pending exact-head verification and owner acceptance. Baseline 2273545a64a0b1c6cceb5eae85d2edb73e751454, AQ-03A #111 accepted. Q10/Q11/Q17 follow-up.

## Boundary and data minimization

Existing public 401 AUTHENTICATION_FAILED, 403 ACCESS_DENIED and resource-safe NOT_FOUND remain unchanged. Existing application authorization, atomic audit/event intents, storage placement, grant rules and transactions remain authoritative. No extra authority lookup, authorization cache, network call, public endpoint or production grant.

SecurityObservation receives only Boundary and Reason enums. Boundaries FILES, POLICY_ADMIN and BACKEND_ADMIN; reasons AUTHENTICATION_FAILED, AUTHORIZATION_DENIED, KEY_SOURCE_UNAVAILABLE, BINDING_UNAVAILABLE, MEMBERSHIP_UNAVAILABLE, ENTITLEMENT_UNAVAILABLE, GRANT_SOURCE_UNAVAILABLE, PERMISSION_UNAVAILABLE. No bearer, claim, actor, tenant, application, file, SQL, provider, exception, request/correlation ID or arbitrary label. Consistent with Kernel v0.3.2 safe telemetry defaults; no resolved request context exists at early authentication failure. Runtime SecurityFailureCounters uses preallocated LongAdders with immutable enum maps; trusted in-process snapshot only, non-atomic across counters, resets at restart. No monitoring exporter, SLO, alerting or public route added. Legacy direct constructors retain no-op sink. Observer RuntimeException is swallowed without changing the decision; trusted sinks must be fast/nonblocking (runtime sink has no I/O). Fatal JVM errors not swallowed.

A source exception emits its bounded source-unavailable reason before existing denial mapping; null entitlement is unavailable, empty binding/false membership/disabled entitlement are ordinary denials. Source overflow/malformed JdbcGrants throws existing neutral GRANT_SOURCE_UNAVAILABLE. Invalid/missing trusted key snapshot (including stale/malformed or no usable configured algorithm) emits KEY_SOURCE_UNAVAILABLE; a valid snapshot with unknown kid, bad signature or claims is authentication failure. Other verifier exceptions are conservatively authentication failure, not evidence of a known outage. Public SecurityFailure has no cause or secret detail; its internal reason is not serialized by HTTP. Counts are observations at enforcement points, not unique denied requests: authority outage may also increment denial, initiation may check more than one grant, and resource-not-found without a grant check is not claimed as an authorization denial. No per-user correlation or forensic audit replacement.
